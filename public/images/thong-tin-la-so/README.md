# Ảnh phần "Thông tin lá số" (Trung Cung) — nơi thay ảnh mà không cần sửa code

Chỉ cần **thay đúng file cùng tên** (giữ đuôi `.jpg`), ảnh mới tự lên site.

| File | Dùng ở |
| --- | --- |
| `trung-cung-web.jpg` | Nền Trung Cung trên màn hình (máy tính, tablet, điện thoại) của lá số **Xuyên Tam Diệm**, và bức tranh mờ dần hiện sau form ở trang `/lap-la-so` |
| `trung-cung-in.jpg` | Nền Trung Cung khi **in / xuất PDF** lá số Xuyên Tam Diệm |

## Lưu ý khi thay ảnh

- Kích thước hiện tại: 1600 × 1999 px (dọc). Ảnh khác tỉ lệ vẫn dùng được nhưng có thể bị cắt phần trên.
- Bản màn hình bị hạ 3% xuống dưới đáy, bản in phủ 103% chiều cao; phần **đáy tranh** nên có nền sát tông giấy để không lộ mép.
- Hai file nên cùng một bức tranh; bản in đã chỉnh màu khớp nền giấy in (`public/images/print/ngoc-am-print-bg-v4.jpg`), bản web khớp màu giấy của lá số.
- Lá số Tử Vi gốc (`/la-so`) vẫn dùng bộ ảnh riêng trong `public/images/tuvi/` (`trung-cung-desktop.jpg`, `-mobile.jpg`, `-print.jpg`).
